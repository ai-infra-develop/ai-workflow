# Review Checklist

Review the code analysis and decide if it's ready for fixes.

## Input

- analysis: Read from analysis.md (run_dir)

## Output

Write to `verdict.txt`:
- Write "approved" if analysis is comprehensive and actionable
- Write "rejected" if analysis is incomplete or missing critical areas

Write to `review-comments.md`:
- Specific feedback on what's good and what needs improvement
- If rejected, explain which sections are missing or inadequate
