# Analyze Code

Analyze the source code for potential issues, improvements, and alignment with architecture.

## Input

- code: Read from src/main.py (repo_dir)
- architecture: Read from ARCHITECTURE.md (repo_dir)

## Output

Write to `analysis.md`:
1. Code quality issues (duplication, complexity, naming)
2. Architecture alignment (does it follow patterns in ARCHITECTURE.md?)
3. Missing error handling
4. Suggestions for improvement
